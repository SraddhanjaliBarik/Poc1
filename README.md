In this Proof of Concept, Sraddhanjali built a real time IoT data pipeline by integrating a system with a public MQTT broker to collect sensor metrics such as temperature, humidity, battery levels, and device health signals. She developed Python scripts to subscribe to MQTT topics, parse and preprocess incoming messages and also generated simulated data using a TDengine broker to validate pipeline behaviour under multiple scenarios. The processed time series data was ingested into InfluxDB using a structured measurement/tag model and visualized in Grafana to enable live monitoring and trend analysis. She performed thorough data validation—including completeness, accuracy, and timestamp consistency checks—and carried out end to end testing of an MCP model to ensure reliable, smooth functioning across the entire pipeline, from ingestion to storage to final visualization.
